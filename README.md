# 课程知识点答疑台

> 基于检索增强生成（RAG）的课程答疑与知识回溯系统
> —— 把课程资料整理成"问不倒、可溯源"的智能助教

课程知识点答疑台面向高校课程答疑场景：将课程教学资料整理为可检索的知识库，学生用**自然语言**提问即可获得**分点讲解**，回答同步展示**依据来源**；对知识库未覆盖的问题，系统**明确拒答**，绝不编造内容。

---

## 一、核心特性

| 特性 | 说明 |
|---|---|
| 💬 自然语言问答 | 用日常语言提问，系统检索相关课程资料后生成「概念解释 · 适用条件 · 易错点」式分点讲解 |
| 🔍 回答可溯源 | 每条回答下方列出依据的**来源文件名、原文片段与相关度**，点击即可阅读全文 |
| 🚫 无依据拒答 | 知识库没有相关内容时明确提示"未找到依据"，不会生成无来源的答案（例如问"红烧肉怎么做"会被拒答） |
| 🧵 多轮追问 | 支持连续追问与指代理解（"那它呢？"自动补全为上一话题），上下文自然衔接 |
| ⚡ 流式输出 | 回答逐字实时显示，无需等待完整生成 |
| 🗺️ 课程知识图谱 | 3D 圆环展示 10 个 Python 知识领域，拖动旋转、点击进入该领域文档列表 |
| 📖 文档阅读 | 534 篇答疑文档全文可读，支持 Markdown 渲染与代码高亮 |
| 📝 会话与笔记 | 历史会话自动保存、随时回看；支持给回答做笔记（保存在本机浏览器） |
| 📊 质量可度量 | 内置固定测试集，自动统计引用命中率（Hit@k）、MRR 与拒答率 |

## 二、界面导览

系统为单页应用，共两屏，点击屏幕右侧的圆点指示器即可切换。

**第一屏 · 课程答疑** —— 对话式问答主界面

- 顶部显示「文档服务 / 问答服务」运行状态指示灯
- 左侧栏：历史会话列表，可新建会话、回看历史
- 中央：输入问题后流式返回分点讲解，下方附来源卡片（文件名、相关度、片段预览）
- 点击来源卡片可跳转阅读该文档全文

**第二屏 · 课程知识图谱** —— 知识领域浏览

- 3D 圆环展示全部知识领域卡片（领域名、英文名、文档数、简介），自动慢速旋转
- 拖动圆环切换视角，正对观察者的卡片高亮发光
- 点击领域卡片，右侧滑出该领域的文档列表，选择文档即可全文阅读

| 知识领域 | 内容 | 文档数 |

| 函数 | 定义、参数与作用域 | 57 |

| 文件操作 | 读写、路径与上下文管理 | 43 |

## 四、快速开始

### 4.1 环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 及以上（Linux / macOS 亦可） |
| Python | 3.11 |
| Node.js | 18 及以上（前端构建使用） |
| 内存 | 建议 4 GB 及以上 |
| 模型密钥 | OpenAI 兼容接口的 LLM 密钥（在项目根目录 `.env` 中配置 `LLM_API_KEY` / `LLM_MODEL` / `LLM_BASE_URL`） |

> 嵌入模型（jina-embeddings-v3）与精排模型（bge-reranker-base）**本地运行**，不依赖外部模型服务；仅有文本生成环节调用 LLM。

### 4.2 一键启动（推荐）

在 PowerShell 中执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start-all.ps1
```

脚本会依次完成：清理端口 → 启动文档服务 → 启动问答服务 → 启动前端 → 服务就绪后自动打开浏览器（http://127.0.0.1:5173）。

停止全部服务：

```powershell
powershell -ExecutionPolicy Bypass -File .\stop-all.ps1
```

### 4.3 手动启动（三步）

```bash
# 1. 文档服务（端口 8000）
python -m docs_service

# 2. 问答服务（端口 8001）
python -m rag_service

# 3. 前端（端口 5173）
cd web && npm install && npm run dev
```

### 4.4 首次启动说明

- **首次启动较慢**：问答服务需构建向量库（本机 CPU 约 12~15 分钟）并预热精排模型（约 30 秒）。**只发生一次**，之后每次启动均为秒级。
- 两个服务顶部状态灯全部亮起后即可提问；启动期间可先行浏览第二屏（知识图谱不依赖问答服务）。

## 五、使用指南

**提问**

1. 在答疑主页输入问题，例如："Python 里怎么捕获异常？"、"怎么把多个字符串拼成一个？"
2. 回答以分点形式流式展示：概念解释 → 适用条件 → 易错点。
3. 回答下方查看来源：文件名、相关度、原文片段；点击可跳转全文。

**追问**

- 直接继续提问即可，系统会结合上文理解："那如果文件不存在呢？"
- 追问历史随会话保存，侧边栏可随时切换、回看。

**浏览知识库**

1. 切到「课程知识图谱」屏，拖动圆环浏览 10 个领域；
2. 点击领域卡片 → 右侧列出该领域全部文档 → 点击文档全文阅读。

**笔记**

- 每条回答下方有「存笔记」按钮，点击即可存入笔记；笔记保存在本机浏览器，导出 / 清空均在笔记抽屉中操作。

**边界行为**

- 知识库未覆盖的问题（含 Python 相关的"陷阱题"），系统会明确回答"未找到依据"，不会强行作答。

## 六、质量与评测

系统内置固定测试集（15 条库内问题 + 5 条库外拒答问题），从"词面直白 / 换个说法 / 口语化"三个维度考察检索链路。实测结果：

| 指标 | 纯向量检索（基线） | 检索 + 改写 + 精排（全链路） |
|---|---|---|
| 首位命中率 Hit@1 | 40.0% | **53.3%** |
| MRR（平均倒数排名） | 0.544 | **0.627** |
| 库外拒答 | — | 相关度阈值守卫 |

运行 `python eval/eval.py` 可随时复测并输出评测报告。

## 七、常见问题（FAQ）

**Q：顶部状态灯没亮，提问没反应？**
A：等待约 30 秒让问答服务完成预热；仍不亮则按 [start-all.ps1](start-all.ps1) 重启（脚本会自动清理 8000 / 8001 端口残留进程）。

**Q：想清空所有聊天记录？**
A：删除 `knowledge/chat_history.db` 文件后重启问答服务即可（该文件为运行时数据，删除后自动重建）。

**Q：更换了课程资料，但检索到的还是旧内容？**
A：正常情况下系统通过"语料指纹"自动重建向量库（首次约 12~15 分钟）。若重建前问答服务正在运行，请先停止服务再重建，避免文件锁冲突。

**Q：回答内容会不会编造？**
A：不会。生成环节仅依据检索命中的课程资料组织答案，并要求"先回答资料可支撑的部分"；无依据时明确拒答，且每条回答附带可点击的来源片段。

## 八、技术架构（简述）

```
浏览器（Vue3 + Vite）
   │  HTTP / SSE 流式
   ├── 文档服务 FastAPI（:8000）── 语料列表 / 文档全文
   └── 问答服务 FastAPI（:8001）── 多轮会话 / 流式问答
              │
              └── RAG 流水线：检索 → 查询改写 → 精排（bge-reranker）→ LLM 生成
                       └── 知识库：Chroma 向量库（嵌入：jina-embeddings-v3）
```

核心原则：**回答可溯源**（每条结论对应可见来源）、**检索是地板**（检索只负责召回，拒答与清洗分层实现）、**库是语料的函数**（指纹不符自动重建）。

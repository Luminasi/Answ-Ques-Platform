# 如何将一个十进制数转换成二进制？

**知识点**：Python Fundamental Syntax ｜ **问题类型**：Beginner ｜ **答案类型**：Explain in Detail

将十进制数转换成二进制，可以使用除以2的方法，具体步骤如下：

1. 将十进制数除以2。
2. 记录下商和余数。
3. 再将商除以2，记录下新的商和余数。
4. 重复这个过程，直到商为0。
5. 将记录的余数倒序排列，这个倒序排列的序列就是对应的二进制数。

例如，将十进制数`29`转换成二进制：

1. 29 ÷ 2 = 14 余 1
2. 14 ÷ 2 = 7 余 0
3. 7 ÷ 2 = 3 余 1
4. 3 ÷ 2 = 1 余 1
5. 1 ÷ 2 = 0 余 1

记录下的余数为1, 0, 1, 1, 1，倒序排列后为 11101，这就是29的二进制表示。

如果你想使用Python来进行这个转换，可以直接使用内置的`bin()`函数。这里是一个简单的例子：

```python
number = 29
binary_number = bin(number)
print(binary_number)  # 输出将会是 '0b11101'
```

`bin()`函数会返回一个以'0b'开头的字符串，表示这是一个二进制数。如果你需要不带'0b'的纯二进制数，可以使用`binary_number[2:]`来获取。

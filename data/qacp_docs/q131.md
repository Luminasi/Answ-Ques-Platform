# 如何使用 for循环遍历集合set并打印出每个元素？

**知识点**：Control Flow Structures ｜ **问题类型**：Beginner ｜ **答案类型**：Explain in Detail

在Python中，使用 `for` 循环遍历集合是一种简单有效的方法。集合（set）是一个无序且不包含重复元素的数据结构，非常适合处理独特元素的集合。以下是如何遍历集合并打印每个元素的例子：

```
my_set = {1, 2, 3, 4, 5}  # 定义一个集合
for element in my_set:
    print(element)
```

在这个例子中，`my_set` 是一个包含数字的集合。`for` 循环依次从集合中取出每个元素，并将其存储在变量 `element` 中，然后打印出来。

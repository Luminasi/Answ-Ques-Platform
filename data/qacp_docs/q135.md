# for循环的基本结构是什么？

**知识点**：Control Flow Structures ｜ **问题类型**：Beginner ｜ **答案类型**：Explain in Detail

在Python中，`for` 循环就像一只勤劳的蜜蜂，在一个花圃中（即序列）逐一飞到每朵花上（即序列中的每个元素）。每次循环，蜜蜂（循环变量）都会访问一朵新的花，直到所有的花（序列中的所有元素）都被访问过。

`for` 循环的基本结构如下：

```
for element in sequence:
    # 'element' 是当前循环中正在处理的元素（即“花”）。
    # 'sequence' 是所有要处理的元素的集合（即“花圃”）。
    # 在这里，你可以添加对 'element' 执行的操作。
    # 例如，打印每个元素（花名）：
    print(element)
```

在这个例子中，`sequence` 可以是任何Python支持的序列类型，如列表（list）、元组（tuple）或字符串（str）。下面是一个具体的例子：

```
flowers = ['玫瑰', '茉莉', '牡丹', '菊花']
for flower in flowers:
    print(flower)
```

运行这段代码，你会看到每种花的名字依次被打印出来，就像蜜蜂逐一访问花圃中的每朵花一样。

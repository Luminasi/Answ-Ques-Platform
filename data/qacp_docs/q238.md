# 如何合并两个列表？

**知识点**：Strings and Common Data Structures ｜ **问题类型**：Experience in Programming ｜ **答案类型**：In-depth Explanation

合并两个列表在Python中是一个非常简单的操作。有几种常用方法可以实现这一目标：

使用 + 运算符：

这是最简单的方法，直接将两个列表相加。
示例：

list1 = [1, 2, 3]
list2 = [4, 5, 6]
combined_list = list1 + list2
# combined_list 将是 [1, 2, 3, 4, 5, 6]
使用 extend() 方法：

你可以使用列表的 extend() 方法来添加另一个列表的元素。
与 + 运算符不同，extend() 会在原地修改列表，而不是创建一个新列表。
示例：

list1 = [1, 2, 3]
list2 = [4, 5, 6]
list1.extend(list2)
# 现在 list1 将是 [1, 2, 3, 4, 5, 6]
使用 * 运算符（列表解包）：

列表解包是Python的一种高级特性，可以在创建新列表时将其他列表的元素包含进来。
示例：

list1 = [1, 2, 3]
list2 = [4, 5, 6]
combined_list = [*list1, *list2]
# combined_list 将是 [1, 2, 3, 4, 5, 6]
使用列表推导式：

对于更复杂的合并逻辑，可以使用列表推导式。
示例：

list1 = [1, 2, 3]
list2 = [4, 5, 6]
combined_list = [item for sublist in [list1, list2] for item in sublist]
# combined_list 将是 [1, 2, 3, 4, 5, 6]
这些方法可以根据你的具体需求和场景进行选择。如果你只是简单地合并两个列表，使用 + 运算符或 extend() 方法会非常方便。如果你的合并逻辑更复杂，或者你想在合并时进行一些额外的操作，列表推导式可能会更合适。

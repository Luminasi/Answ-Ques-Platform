# 如何复制一个列表？

**知识点**：Strings and Common Data Structures ｜ **问题类型**：Beginner ｜ **答案类型**：Explain in Detail

在Python中复制列表，其实就是创建一个已知列表的一个副本，创建列表副本以下3种常用方法，我们通过一个具体的应用场景来学习一下。
应用场景：产品库存管理
假设你是一家电子商务公司的产品经理，正在处理产品库存的数据。你有一个包含所有产品库存数量的列表。由于需要对这些数据进行一系列操作（比如预测、调整或分析），同时保留原始库存数据不变，所以你需要创建这个列表的一个副本。

原始库存列表：

original_inventory = [120, 150, 200, 300, 400, 500]
复制这个列表
1、使用列表的 copy() 方法：这是复制列表的一种简单方法。
示例代码：

inventory_copy = original_inventory.copy()
2、使用列表切片：使用空的切片操作（[:]）来复制列表。
示例代码：

inventory_copy = original_inventory[:]
3、使用 list() 构造函数：将原始列表作为参数传递给 list() 函数。
示例代码：

inventory_copy = list(original_inventory)
现在你有了库存数据的一个副本 inventory_copy，可以在上面进行各种操作，比如预测未来的库存需求、计算平均库存等，而不会影响到原始的库存数据 original_inventory。这种方法确保了数据的完整性和一致性，在数据分析和处理中非常重要。
Tips:
1、在对列表进行操作之前考虑是否需要复制，以避免意外修改原始数据。

2、注意以上这3种方法（使用 `copy()` 方法、列表切片、使用 `list()` 构造函数）都是进行浅复制（shallow copy），也就是说，如果列表中还包含了引用类型（例如其他列表），复制的将只是引用地址，而不是被引用对象本身的深层复制（deep copy）。如果需要进行深层复制，可以使用 `copy` 模块的 `deepcopy()` 方法。

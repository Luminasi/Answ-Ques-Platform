# 如何合并两个字典？

**知识点**：Strings and Common Data Structures ｜ **问题类型**：Beginner ｜ **答案类型**：Explain in Detail

Python 提供了几种不同的方法来合并两个字典。这里介绍两种主要的方法：使用字典解包和使用 `update()` 方法。

### 方法1：使用字典解包

字典解包是 Python 3.5 及更高版本中引入的一种语法，允许你在创建新字典时“解包”一个或多个字典。其语法为 `{**dict1, **dict2}`，其中 `**` 是解包运算符，它将字典中的键值对展开。

以下是使用字典解包的例子：

```
# 商品基本信息
product_details = {
    'id': '34356',
    'name': 'DJI Mini 4 Pro',
    'brand': '大疆',
    'category': 'Electronics'
}

# 商品库存和价格信息
inventory_details = {
    'id': '34356',
    'stock_quantity': 400,
    'price': 5288,
    'discounted_price': 4788
}

# 使用字典解包合并字典
combined_details = {**product_details, **inventory_details}

print(combined_details)
```

在这个例子中，`combined_details` 将包含 `product_details` 和 `inventory_details` 中的所有键值对。如果两个字典中有相同的键，则 `inventory_details` 中的值会覆盖 `product_details` 中对应的值。这是因为在解包时，后面的字典中的键值对会覆盖前面字典中的同名键。

最终合并后字典成功地结合了商品的基本信息和库存及价格信息。输出结果如下：

```python
{
    'id': '34356',
    'name': 'DJI Mini 4 Pro',
    'brand': '大疆',
    'category': 'Electronics',
    'stock_quantity': 400,
    'price': 5288,
    'discounted_price': 4788
}
```

### 方法2：使用 `update()` 方法

`update()` 方法用于将一个字典的键值对更新到另一个字典中。如果有重复的键，被 `update()` 的字典中的键值对会被更新的字典中的键值对覆盖。

以下是使用 `update()` 方法的例子：

```
# 商品基本信息
product_details = {
    'id': '666888',
    'name': 'NVIDIA RTX 4090 24G 涡轮版',
    'brand': '英伟达',
    'category': 'Electronics'
}

# 商品库存和价格信息
inventory_details = {
    'id': '666888',
    'stock_quantity': 10,
    'price': 17999,
    'discounted_price': 17899
}

# 使用 update() 方法合并字典
product_details.update(inventory_details)

print(product_details)
```

使用 `update()` 后，`product_details` 将被更新为包含两个字典中的所有键值对。同样地，如果有重复的键，`inventory_details` 中的值会覆盖 `product_details` 中的值。不同于字典解包，`update()` 方法会直接修改第一个字典，而不会创建新的字典。

合并后的字典 `product_details` 包含以下键值对（输出结果）：

```python
{
    'id': '666888',
    'name': 'NVIDIA RTX 4090 24G 涡轮版',
    'brand': '英伟达',
    'category': 'Electronics',
    'stock_quantity': 10,
    'price': 17999,
    'discounted_price': 17899
}
```

### 注意事项

- **字典解包**：这种方法会创建一个新的字典，而原始的两个字典保持不变。
- **使用 `update()` 方法**：这种方法会直接修改第一个字典，不会创建新的字典，这意味着原始的第一个字典将被改变。

根据你的具体需求（是否需要保留原始字典不变），你可以选择合适的方法来合并字典。如果你需要保留原始字典不变，使用字典解包可能更合适；如果你不介意修改原始字典，`update()` 方法会是一个简单的选择。

# 如何将字典的键或值转换为列表？

**知识点**：Strings and Common Data Structures ｜ **问题类型**：Beginner ｜ **答案类型**：Explain in Detail

在Python编程中，有时我们可能需要单独处理字典中的键（Keys）或值（Values）。将它们转换为列表不仅方便进行迭代遍历，还有助于执行其他列表特有的操作，如排序、去重等。下面我们将介绍如何转换，以及在实际应用场景中的一些例子。

### 转换键（Keys）为列表

- **基本转换：**

  假设你有一个字典 `my_dict`，你可以使用 `keys()` 方法来获取字典的所有键，然后使用 `list()` 函数将它们转换为列表。


```
my_dict = {'a': 1, 'b': 2, 'c': 3}
keys_list = list(my_dict.keys()) # 使用list()函数将my_dict转换为列表keys_list
print(keys_list) # 输出结果：['a', 'b', 'c']
```

**实际应用场景：**

假设你正在处理一份调查问卷的数据，其中每个参与者的回答都存储在一个字典中，字典的键是问题编号。如果你想统一更新或验证所有问题编号（键），可以先将键转换为列表进行操作。

 ```
 questionnaire = {'Q001': 'Answer1', 'Q002': 'Answer2', ...}
 question_keys = list(questionnaire.keys())
 # 下面可以对问题编号进行排序、验证或其他操作...
 ```

### 转换值（Values）为列表

- **基本转换：**

  如果你想获取字典的所有值并将它们转换为列表，你可以使用 `values()` 方法，然后使用 `list()` 函数。

```
values_list = list(my_dict.values())
print(values_list) # 输出结果：[1, 2, 3]
```

**实际应用场景：**

如果你处理的是一组统计数据，其中字典的值代表某种计数，你可能需要对这些数值进行数学运算，如求和、平均或其他统计分析。

 ```
 scores = {'安柏': 90, '七七': 85, '派蒙': 88} # 学员分数
 scores_list = list(scores.values()) # values()：获取scores的所有value，list()：并将它们转换为列表
 average_score = sum(scores_list) / len(scores_list) #计算平均分
 ```

在这些情况下，将字典的键或值转换为列表，可以提供更多的灵活性和方便性，特别是在需要对这些键或值进行进一步操作（如排序、过滤等）时。

### 小贴士

- `keys()` 和 `values()` 方法返回的不是真正的列表，而是一个可迭代的视图。如果你希望得到一个列表，就需要如上所示地使用 `list()` 函数进行转换。
- 这种转换在数据处理中非常有用，特别是在需要对字典的键或值进行进一步操作时。

通过以上方法，你可以轻松地从字典中提取出键或值，并将它们转换为列表进行后续操作。

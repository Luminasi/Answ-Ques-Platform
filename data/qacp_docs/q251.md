# 如何获取字典中的值？

**知识点**：Strings and Common Data Structures ｜ **问题类型**：Beginner ｜ **答案类型**：Explain in Detail

在Python中，有多种方法可以从字典中获取值。最直接的方法是通过键来访问，但是推荐使用 `get()` 方法，因为它提供了一种更安全的方式来处理可能不存在的键。

### 基本方法：直接通过键访问

直接通过键来访问字典中的值是最基本的方法：

```
value = dictionary[key]
```

但是，如果键不存在于字典中，这种方法会抛出一个 `KeyError`。

### 推荐方法：使用 `get()` 方法

`get()` 方法允许你在尝试访问字典中不存在的键时避免 `KeyError` 的产生。使用 `get()` 方法时，如果指定的键不存在于字典中，可以让方法返回一个默认值，而不是抛出异常。

#### 基本用法

```
value = dictionary.get(key, default_value)
```

- `key`：你想从字典中获取的键。
- `default_value`：可选参数，如果键不存在时返回的值。如果不提供，默认为 `None`。

#### 示例

假设你有一个存储学生分数的字典，你想安全地获取一个学生的分数，如果学生名不在字典中，返回一个默认值（如0分）。

```
scores = {'派蒙': 95, '莫娜': 85, '安柏': 90}

# 安全获取
score_of_hutao = scores.get('胡桃', 0)
```

在这个例子中，由于 '胡桃' 不在 `scores` 字典中，`get()` 方法将返回默认值0。这样，即使 '胡桃' 的分数不存在，代码也不会引发错误。

### 为什么使用 `get()` 方法

- **防止错误**：直接通过键访问字典时，如果键不存在，会抛出 `KeyError`。使用 `get()` 方法可以避免这种情况。
- **代码清晰简洁**：`get()` 方法提供了一种简洁的方式来获取字典中的值，无需编写额外的条件语句来检查键是否存在。

总的来说，使用 `get()` 方法是处理字典时的最佳实践，它使得你的代码更加健壮和易于维护。不过也可以多了解其他方法，以便在不同的情况下选择最合适的方法。

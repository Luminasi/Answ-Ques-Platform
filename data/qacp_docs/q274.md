# 为什么需要函数？

**知识点**：Functions ｜ **问题类型**：Beginner ｜ **答案类型**：Explain in Detail

在回答之前，我们先看一个游戏的例子。
想象一下，我们在玩一个叫《王者荣耀》的游戏，里面有一个法师角色，需要多次使用一个特定的攻击法术。我们可以通过两种不同的编程方法来实现这个功能。

**方法1：不使用函数**

```
# 第一次攻击
print("发动攻击！")
print("造成了10点伤害。")

# 第二次攻击
print("发动攻击！")
print("造成了10点伤害。")

# 第三次攻击
print("发动攻击！")
print("造成了10点伤害。")
```

在这种方法中，我们每次发动攻击都要重复写两行代码。如果攻击次数增加，代码会变得冗长且重复。

**方法2：使用函数**

```
# 定义函数：attack
def attack():
    print("发动攻击！")
    print("造成了10点伤害。")

# 第一次攻击
attack()

# 第二次攻击
attack()

# 第三次攻击
attack()
```

这里，我们定义了一个名为`attack`的函数，它封装了发动攻击的所有指令。当我们想要攻击时，只需调用`attack()`。

现在，如果你想改变攻击的效果（比如伤害从10点增加至20点），采用方法1，你需要修改3处代码，而采用方法2，只需要在`attack`函数内部修改1处代码。

这个例子清楚地展示了使用函数的优势：

- **重用代码**：一次编写，多次调用。当某段代码需要在多个地方使用时，可以将其写成一个函数，随后需要时调用。
- **易于调试和维护**：只需修改函数内部的代码，这使得调试和维护更加容易。
- **组织和管理代码**：函数有助于把代码分组，使其更加清晰和易于管理。

此外，函数还可以接受参数（比如攻击力或攻击类型）并返回结果（比如攻击的总伤害）。例如，我们可以将`attack`函数改进为接受攻击力作为参数：

```
def attack(damage):
    print("发动攻击！")
    print(f"造成了{damage}点伤害。")

# 使用不同的攻击力
attack(10)
attack(20)
```

这种带参数的函数更具灵活性，能够适应更多的场景，并且进一步简化任务和逻辑，在开发中非常有用。

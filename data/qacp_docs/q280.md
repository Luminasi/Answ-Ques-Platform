# 函数与模块有什么区别？

**知识点**：Functions ｜ **问题类型**：Beginner ｜ **答案类型**：Explain in Detail

函数 vs 模块：工具箱中的故事
想象一下，你有一个工具箱，用于各种家居维修工作。

函数：工具箱里的单一工具
角色：函数就像是工具箱里的单一工具，比如螺丝刀、钳子或锤子。每个工具都有其特定的用途。
任务：一个螺丝刀（函数）可能专门用来拧紧或松开螺丝（执行一个特定的任务）。
示例：

def tighten_screw(screw):
    return f"拧紧了{screw}螺丝"
每次调用tighten_screw函数，就像是使用螺丝刀拧紧一个螺丝。
模块：整个工具箱
角色：模块则像是整个工具箱，包含了多个工具（函数），每个工具有不同的用途。
组成：你的工具箱（模块）可能包括螺丝刀、钳子、锤子（函数），还有一些固定的配件和说明书（变量和类）。
示例：

# toolbox.py
def tighten_screw(screw):
    return f"拧紧了{screw}螺丝"

def cut_wire(wire):
    return f"剪断了{wire}电线"

def hammer_nail(nail):
    return f"敲打了{nail}钉子"
这个模块（工具箱）有多个功能（工具/函数）。
应用场景
当你需要挂一幅画（编写特定的功能），你可能只需要从工具箱中取出一个锤子（调用一个函数）。
但当你在进行整个房间的装修（构建一个大型项目）时，你需要整个工具箱（模块），因为每个工具都有不同的用途。
总结
函数（单一工具）：专注于执行一个具体的动作，如拧紧螺丝、剪断电线。
模块（工具箱）：由多个函数组成，代表一整套可以协同工作的工具集合。
在编程中，我们通过函数来实现具体的操作，而通过模块来组织这些函数和相关的变量、类。这种组织方式使我们能够有效地管理复杂的编程项目，就像一个装满各种必需工具的工具箱，准备好应对各种修理任务。

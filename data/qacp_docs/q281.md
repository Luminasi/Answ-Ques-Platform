# 函数与过程有什么区别？

**知识点**：Functions ｜ **问题类型**：Experience in Programming ｜ **答案类型**：In-depth Explanation

函数（Function）和过程（Procedure）在编程中常被提及，它们都是封装代码的方式，但在某些编程语言和编程模型中，它们之间存在一些关键区别：

函数
返回值：函数通常会返回一个值。在许多编程语言中，如果一个代码块执行了一些操作并返回了一个结果，那么这个代码块被称为函数。
表达式评估：函数可以被视为一种表达式，它处理输入（参数），并返回一个值。
示例：在Python中，任何使用def关键字定义并且返回一个值的代码块都是一个函数。

def add(a, b):
    return a + b
这个add函数接受两个参数，并返回它们的和。
过程
无返回值：过程通常不返回值，或者说它的返回类型是“空”或“无”。它可能执行一些操作，比如修改数据、打印信息或与外部设备交互，但不返回任何东西。
操作执行：过程更多地被看作是执行一系列操作的一段代码，而不强调返回值。
示例：在某些编程语言中（如Pascal），过程是一种不返回值的特殊代码块。
pascal

procedure ShowMessage;
begin
  WriteLn('Hello, World!');
end;
这个ShowMessage过程在被调用时会打印一条信息，但不返回任何值。
总结
函数 强调“计算”和“返回值”。
过程 强调“执行动作”且通常不返回值。
在现代编程实践中，特别是在像Python这样的语言中，这两个术语有时被交替使用，因为即使定义为函数的代码块不返回值，它也通常被称为函数。但在一些更旧或更严格的编程语言中，函数和过程的区别更为明显。

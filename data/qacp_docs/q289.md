# 什么是自定义函数？

**知识点**：Functions ｜ **问题类型**：Beginner ｜ **答案类型**：Explain in Detail

想象自定义函数就像是你自己设计的工具。比如说，你经常需要测量东西的长度，但是市面上的尺子并不符合你的特殊需求。于是，你决定自己制作一个尺子，它有一些特别的刻度，完全符合你的需求。每次当你需要测量东西时，你就可以用这个特制的尺子，而不是每次都去重新创造一个新的测量工具。

代码示例：

假设我们要编写一个自定义函数来计算一个数字的立方（即数字的三次方）。在没有这个函数的情况下，每次计算一个数字的立方时，我们都需要重复写 number * number * number。但有了这个自定义函数，我们就可以简单地调用它。


# 定义一个自定义函数
def cube_number(number):
    return number * number * number

# 使用这个自定义函数
result = cube_number(4)
print(result)  # 输出: 64
在这个例子中，cube_number 是一个自定义函数，它接受一个参数（number），并返回这个数字的立方。这样，每当你需要计算一个数字的立方时，只需要调用这个函数并传入相应的数字即可。

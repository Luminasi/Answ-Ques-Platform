# 常用的内置函数都有哪些？

**知识点**：Functions ｜ **问题类型**：Beginner ｜ **答案类型**：Explain in Detail

Python有很多内置函数，之所以称它们为“内置函数”，是因为无需导入任何模块就可以使用它们。以下是一些最常见和最有用的内置函数示例：

1. `len()` - 该函数用于返回对象（列表，字典，字符串等）的项目数。

```python
list = [1, 2, 3, 4, 5]
print(len(list)) # 输出: 5
```

2. `type()` - 用于返回一个对象的类型。

```python
print(type(123)) # 输出: <class 'int'>
```

3. `str()`, `int()`, `float()` - 用于将值转换为特定类型。

```python
print(type(str(123))) # 输出: <class 'str'>
```

4. `print()` - 用于在控制台打印文本。

```python
print("Hello, world!") # 输出: Hello, world!
```

5. `range()` - 生成一个数字序列。

```python
# create a list of numbers from 0 to 4
numbers = list(range(5))
print(numbers) # 输出: [0, 1, 2, 3, 4]
```

6. `sorted()` - 返回一个排序的列表。

```python
numbers = [5, 1, 9, 3, 7]
sorted_numbers = sorted(numbers)
print(sorted_numbers) # 输出: [1, 3, 5, 7, 9]
```

7. `sum()` - 返回数字的总和。

```python
numbers = [1, 2, 3, 4, 5]
print(sum(numbers)) # 输出: 15
```

8. `min()` 和 `max()` - 分别返回最小值和最大值。

```python
numbers = [1, 2, 3, 4, 5]
print(min(numbers)) # 输出: 1
print(max(numbers)) # 输出: 5
```

以上就是一些常见的内置函数。在实际的数据分析或人工智能工作中，这些函数使用得非常频繁，例如，经常需要获取数据的长度（`len()`）、转换数据类型（`str()`, `int()`, `float()`）等。

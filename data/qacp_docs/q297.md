# 不同类型的函数参数之间的区别是什么？

**知识点**：Functions ｜ **问题类型**：Beginner ｜ **答案类型**：Explain in Detail

每种类型的函数参数有各自的特点，适用于不同的编程场景，简介如下：

1. **位置参数 (Positional Arguments)**:
   - 这些参数必须按照函数定义时的顺序精确传递。
   - **典型场景**: 用于必须按照特定顺序提供的简单和直观的参数，如数学函数（`power(base, exponent)`）或地理位置坐标（`plot(x, y)`）。
2. **关键字参数 (Keyword Arguments)**:
   - 调用者可以在调用函数时指定每个参数的名称，无需关心参数的顺序。（这是关键字参数和位置参数的主要区别）
   - **典型场景**: 用于参数较多或参数顺序不易记忆的情况，以增加代码的可读性。例如，在创建用户资料的函数中使用（`create_user(name="李白", age=30, country="中国")`）。
3. **默认参数 (Default Arguments)**:
   - 函数定义时为某些参数指定默认值，如果调用时未提供，将自动使用这些默认值。
   - **典型场景**: 用于函数参数有常见的标准值或者大多数用例下不需要改变的情况。例如，设置文件操作的模式（`open_file(filename, mode='r')`）。
4. **可变参数 (Variable-length Arguments)**:
   - 使用星号 `*` 定义的参数，如 `*args`，表示函数可以接受任意数量的位置参数。
   - **典型场景**: 用于函数需要处理不确定数量的参数时。这在编写如打印日志、数学运算等需要聚合多个输入的函数时非常有用（`calculate_average(*scores)`）。
5. **关键字可变参数 (Keyword Variable-length Arguments)**:
   - 使用双星号 `**` 定义的参数，如 `**kwargs`，表示函数可以接受任意数量的关键字参数。
   - **典型场景**: 用于需要处理大量命名参数或属性的情况，特别是在编写API、处理复杂配置时非常有用（`create_profile(**user_details)`）。
     - `*args` 用于不确定数量的位置参数，处理时作为元组。
     - `**kwargs` 用于不确定数量的关键字参数，处理时作为字典。
### 示例代码

```
# 位置参数示例
def plot(x, y):
    print(f"Plotting point at ({x}, {y})")

# 关键字参数示例
def create_user(name, age, country):
    print(f"Name: {name}, Age: {age}, Country: {country}")
create_user(name="李白", age=30, country="中国")

# 默认参数示例
def open_file(filename, mode='r'):
    print(f"Opening file {filename} in mode {mode}")
open_file("example.txt")  # 使用默认模式

# 可变参数示例
def calculate_average(*scores):
    average = sum(scores) / len(scores)
    print(f"Average score: {average}")
calculate_average(75, 85, 90)  # 任意数量的分数

# 关键字可变参数示例
def create_profile(**user_details):
    for key, value in user_details.items():
        print(f"{key}: {value}")
create_profile(name="李白", age=30, job_title="诗人", location="长安")
```

# 请举一个实际的例子，说明在什么情况下会用到继承。

**知识点**：Object-Oriented Programming ｜ **问题类型**：Beginner ｜ **答案类型**：Explain in Detail

想象一下，你有一个电子产品制造公司，这个公司生产各种电子设备。所有这些电子设备（比如手机、电视和笔记本电脑）都有一些共同的特性，，例如它们都需要电源来工作，都有制造商信息，以及它们都有一个开关机的功能。我们可以将这些共同特性抽象成一个基类，叫做 `ElectronicDevice`。

```
class ElectronicDevice:
    def __init__(self, manufacturer):
        self.manufacturer = manufacturer
        self.powered_on = False

    def power_on(self):
        if not self.powered_on:
            self.powered_on = True
            return "设备已开启。"
    
    def power_off(self):
        if self.powered_on:
            self.powered_on = False
            return "设备已关闭。"
```

对于智能手机子类 `Smartphone`，我们添加了操作系统属性，并且有一个拨打电话的方法：

```
class Smartphone(ElectronicDevice):
    def __init__(self, manufacturer, operating_system):
        super().__init__(manufacturer)
        self.operating_system = operating_system
    
    def make_call(self, number):
        if self.powered_on:
            return f"正在拨打电话给 {number}..."
        else:
            return "手机已关机，请先开机。"
```

对于电视子类 `Television`，我们添加了屏幕尺寸属性，并且有一个换台的方法：

```
class Television(ElectronicDevice):
    def __init__(self, manufacturer, screen_size):
        super().__init__(manufacturer)
        self.screen_size = screen_size
    
    def change_channel(self, channel):
        if self.powered_on:
            return f"正在切换到 {channel} 频道。"
        else:
            return "电视已关机，请先开机。"
```

当我们创建一个 `Smartphone` 实例并调用它的方法时，输出结果为：

- 开机: "设备已开启。"
- 拨打电话: "正在拨打电话给 123456789..."
- 关机: "设备已关闭。"

当我们创建一个 `Television` 实例并调用它的方法时，输出结果为：

- 开机: "设备已开启。"
- 换台: "正在切换到 CCTV-1 频道。"
- 关机: "设备已关闭。"

通过这个案例，我们可以看到 `Smartphone` 和 `Television` 都继承了 `ElectronicDevice` 的基本特性（如制造商信息和开关机功能），同时还分别增加了自己的独特功能，如 `Smartphone` 的拨打电话功能和 `Television` 的换台功能。这就是继承在面向对象编程中的一个简单实例。通过继承，我们可以重用代码（例如电源管理），同时还可以为特定类型的设备添加专有功能（例如拨打电话或换台）

继承通常在以下阶段被使用：

1. **需求分析阶段**：当我们在规划一个系统的时候，我们会分析出不同对象之间的共同点和差异。如果发现多个对象拥有共同的属性和行为，我们会考虑将这些共性抽象成一个基类。例如，如果我们在设计一个游戏，发现“骑士”和“弓箭手”都是“角色”，都具有“生命值”和“攻击力”这样的属性，以及“移动”和“攻击”这样的行为，那么我们可以创建一个叫做“角色”（Character）的基类，然后让“骑士”（Knight）和“弓箭手”（Archer）继承自这个基类，并添加它们独特的属性和方法。
2. **代码重构**：当一个程序在开发过程中逐渐增加新功能，我们可能会发现代码中存在重复。为了提高代码的可维护性和扩展性，我们可能会对代码结构进行重构，引入继承关系来减少重复。例如，如果最初只有一个“交通工具”类，后来发现需要添加“汽车”和“自行车”类，并且它们与“交通工具”有很多共性，这时我们可以将“交通工具”作为一个基类，让“汽车”和“自行车”继承自它，并添加各自特有的属性和方法。

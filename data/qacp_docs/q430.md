# 当我打印一个对象属性时，为什么输出的是对象的内存地址而不是我定义的值？

**知识点**：Object-Oriented Programming ｜ **问题类型**：Beginner ｜ **答案类型**：Explain in Detail

当您尝试打印一个对象的属性时，如果输出的是对象的内存地址而不是您定义的值，这通常是因为您尝试打印的可能是对象本身而不是其属性。在Python中，每个对象都有一个内存地址，表示该对象在内存中的位置。如果直接打印一个对象，而没有重写该对象的`__str__()`或`__repr__()`方法，Python默认会显示这个对象的内存地址，形如`<__main__.MyClass object at 0x10a58f0d0>`。

要确保打印的是对象的属性值而不是对象的内存地址，您需要确保您正在访问对象的具体属性。例如，如果您有一个名为`Person`的类，它有一个属性`name`，那么您应该这样打印这个属性：

```
class Person:
    def __init__(self, name):
        self.name = name

# 创建Person对象
person = Person("贾清扬")

# 打印name属性
print(person.name)  # 应该输出: 贾清扬
```

如果您希望在打印整个对象时获得更有意义的输出（而不是内存地址），您需要在类定义中重写`__str__()`或`__repr__()`方法。这两个方法允许您定义当对象被转换成字符串时的表现形式。`__str__()`更多用于普通的打印输出，而`__repr__()`旨在给出一个更正式的输出，理想情况下能够通过`eval()`重建该对象。

例如，修改上述`Person`类以包含一个自定义的`__str__()`方法：

```
class Person:
    def __init__(self, name):
        self.name = name

    def __str__(self):
        return f"我叫{self.name}"

person = Person("贾清扬")
print(person)  # 现在将输出: 我叫贾清扬
```

这样，当您打印`Person`类的对象时，输出的将是您在`__str__()`方法中定义的字符串，而不是对象的内存地址。

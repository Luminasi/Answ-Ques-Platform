# 在Python中定义类时，有哪些常见的陷阱和错误我应该避免？

**知识点**：Object-Oriented Programming ｜ **问题类型**：Beginner ｜ **答案类型**：Explain in Detail

1. 忘记`self`: 当定义类方法时，人们常常会忘记在函数开头添加`self`参数。`self`是指向实例本身的引用，它是在调用方法时自动传递的。

   ```python
   class Myclass:
       def method(self):
           pass  # 这是正确的
   
   class Myclass:
       def method():
           pass  # 这是错误的，忘记了`self`
   ```

   

2. 忘记调用父类的`__init__`: 如果你重写了子类的`__init__`方法却忘记调用父类的`__init__`，那可能会使你的父类部分属性未正确初始化。使用`super().__init__()`来处理这个问题。

   ```python
   class Base:
       def __init__(self):
           self.value = 0
   
   class Derived(Base):
       def __init__(self):
           # 忘记调用 Base.__init__(self) 会导致 self.value 属性不存在
           super().__init__()
   
    obj = Derived()  # 正确，self.value 已经初始化.
   ```

3. 修改类变量: 类变量在所有实例之间共享。如果你改变了一个类变量，那么所有实例看到的值都会改变。如果你想让每个实例都有自己的变量，那就应该使用实例变量。

   ```python
   class Myclass:
       class_var = []
   
   a = Myclass()
   b = Myclass()
   a.class_var.append(1)
   # 这将打印 [1]，而不是你可能期望的 []。这是因为 class_var 是共享的
   print(b.class_var)
   ```

4. 使用可变类型作为默认参数: Python的函数或方法默认参数只会在模块加载时计算一次，它们不会每次调用时重新计算。因此，如果你使用可变类型（如一个列表或字典）作为默认值，并且在函数内部修改它，那么这个改变将在下一次调用时仍然存在。

   ```python
   class Myclass:
       def __init__(self, items=[]):  # 不建议使用可变的默认参数
           self.items = items
   
   a = Myclass()
   a.items.append(1)
   b = Myclass()
   # 这将打印 [1]，而不是可能期待的 []
   print(b.items)
   ```

为了避免这些陷阱，你需要完全理解Python的作用域规则，记住所有类和实例的行为，以及理解默认参数是如何工作的。一旦你掌握了这些，你就能写出正确和有效的类。

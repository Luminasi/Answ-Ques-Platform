# 在Python中，全局变量和类变量有什么区别？

**知识点**：Object-Oriented Programming ｜ **问题类型**：Beginner ｜ **答案类型**：Explain in Detail

在Python中，全局变量和类变量是两种不同类型的变量，它们在作用域和用途上有明显的区别。以下是这两者的主要区别，附带一个示例来帮助理解：

### 全局变量

- **定义**: 在整个程序的任何地方都可以访问的变量。通常在模块级别定义。
- **作用域**: 全局作用域。
- **用途**: 用于存储整个程序范围内需要的共享数据。

### 类变量

- **定义**: 在类定义内部，但在所有方法之外定义的变量。由该类的所有实例共享。
- **作用域**: 类作用域。
- **用途**: 当多个对象实例需要共享相同的数据时使用。

考虑一个简单的植物监测系统。在这个系统中，我们有一个全局变量来表示全球平均温度，这对所有植物都是重要的。同时，我们有两个个植物类，每个类具有一个类变量来表示本类植物的水分需求。

### 代码示例

```
# 全局变量 - 全球平均温度
global_avg_temp = 15  # 假设温度单位为摄氏度

class Cactus:
    # 类变量 - 仙人掌的水分需求
    water_need = 20  # 假设单位为升

    def __init__(self, name):
        self.name = name

    def display_info(self):
        return f"植物名称: {self.name}, 水分需求: {Cactus.water_need}升, 全球平均温度: {global_avg_temp}°C"

class Bamboo:
    # 类变量 - 竹子的水分需求
    water_need = 100  # 假设单位为升

    def __init__(self, name):
        self.name = name

    def display_info(self):
        return f"植物名称: {self.name}, 水分需求: {Bamboo.water_need}升, 全球平均温度: {global_avg_temp}°C"

# 创建仙人掌和竹子实例
cactus = Cactus("仙人掌")
bamboo = Bamboo("竹子")

# 打印初始信息
print(cactus.display_info())
print(bamboo.display_info())

# 改变全局变量
global_avg_temp = 16

# 改变仙人掌类变量
Cactus.water_need = 25

# 再次打印信息
print(cactus.display_info())
print(bamboo.display_info())
```

### 输出结果

```
makefile植物名称: 仙人掌, 水分需求: 20升, 全球平均温度: 15°C
植物名称: 竹子, 水分需求: 100升, 全球平均温度: 15°C
植物名称: 仙人掌, 水分需求: 25升, 全球平均温度: 16°C
植物名称: 竹子, 水分需求: 100升, 全球平均温度: 16°C
```

在这个例子中，`global_avg_temp`是一个全局变量，它对所有植物类都有影响。而`Cactus`和`Bamboo`类中的`water_need`是类变量，分别只影响其各自类的实例。改变`Cactus.water_need`不会影响`Bamboo`实例的水分需求，这清楚地展示了全局变量和类变量之间的区别。

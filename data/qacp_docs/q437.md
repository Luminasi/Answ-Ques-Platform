# 为什么我在类的方法外部不能使用self？

**知识点**：Object-Oriented Programming ｜ **问题类型**：Beginner ｜ **答案类型**：Explain in Detail

在 Python 中，`self` 关键字是一个非常特殊的实例，它用于在类的方法内部引用对象自身。这就是为什么你只能在类的方法内部使用 `self`，而不能在类的方法外部使用它的原因。

假设我们有一个名为 `Car` 的类，它有一个方法 `start_engine`。这个方法使用 `self` 来引用类的实例，这样我们就可以访问和修改这个特定车辆实例的属性了。

```
class Car:
    def __init__(self, model):
        self.model = model

    def start_engine(self):
        print(f"{self.model} 的发动机启动了！")
```

在这个例子中，`Car` 类有一个构造函数 `__init__`，它设置车辆的模型。`start_engine` 方法则用来表示启动车辆的行为。在这个方法中，我们使用 `self.model` 来引用这个特定车辆实例的模型。

现在，如果你尝试在类的外部使用 `self`，比如：

```
def external_function():
    print(self.model)  # 这里会出错，因为 'self' 在这个上下文中没有定义
```

这个 `external_function` 函数不是 `Car` 类的一部分，因此它没有自动获得对任何 `self` 的访问权。这就是为什么在类的方法外部不能使用 `self` 的原因：它只在定义为类一部分的方法内有意义，因为只有在那里，`self` 才表示类的一个实例。

# 双下划线（__）在Python中有什么特殊含义？

**知识点**：Object-Oriented Programming ｜ **问题类型**：Experience in Programming ｜ **答案类型**：In-depth Explanation

在 Python 中，双下划线（__）主要有两种使用场景，分别是“双下划线函数（Magic or Dunder Methods）”和“名称修饰（Name Mangling）”。

双下划线函数（Magic or Dunder Methods）：这些是 Python 中的特殊保留方法，它们会在特定情况下被自动调用。例如，__init__ 方法在创建新对象时被调用，而 __add__ 方法则在使用 + 运算符进行数学运算时被调用。如下代码示例：


class Book:
    def __init__(self, title):
        self.title = title

    def __str__(self):
        return f'Book: {self.title}'

b = Book('Harry Potter')  
print(b)  # 输出：Book: Harry Potter
在这个例子中，Book 类定义了两个双下划线方法：__init__ 和 __str__。__init__ 方法在创建对象时调用，__str__ 方法在尝试将对象转换为字符串时调用。

名称修饰（Name Mangling）：这是一种 Python 用于防止命名冲突的机制，特别用于处理所谓的“私有”属性。当属性名称以双下划线开头但不以双下划线结尾时，Python 会自动更改这些属性的名称。这种更改是通过在属性名前加上一个下划线和类名来实现的。例如，__secret_value 会变成 _ClassName__secret_value。这种机制使得这些属性在类的外部不容易被直接访问，从而实现了一种封装。

代码示例：


class TestClass:
    def __init__(self):
        self.__secret_value = 1

obj = TestClass()
print(obj.__secret_value)  # 这会抛出 AttributeError，因为 __secret_value 名字已被改变
在此示例中，我们不能直接通过 obj.__secret_value 访问私有属性，因为名称已被 Python 自动更改。如果我们仍然需要访问这个属性，可以通过修改后的名称 _TestClass__secret_value 来访问：


print(obj._TestClass__secret_value)  # 输出: 1
但应谨慎使用这种方法，因为它违背了类的封装原则。

# 如何在Python中定义一个类的基本结构？

**知识点**：Object-Oriented Programming ｜ **问题类型**：Beginner ｜ **答案类型**：Explain in Detail

在Python中，定义一个类通常涉及以下几个主要部分：

1. **类名**：这是类的标识。按照惯例，类名使用大驼峰命名法（CamelCase），即每个单词的首字母大写，不使用下划线。例如，`House`。
2. **类属性**：这些是定义在类内部的变量，可以被类的所有实例共享。例如，可以有一个类属性来表示房屋的总数。
3. **构造器方法（\**init\**）**：这是一个特殊方法，每当创建新的类实例时，它就会被调用。用于初始化实例属性或执行类实例创建时的其他必要操作。
4. **实例属性**：这些是在构造器中定义的属性，用于存储特定于每个类实例的数据。
5. **其他方法**：这些是定义在类中的函数，用于描述类的行为或功能。

以下是一个示例模板，展示了一个基本的类定义：

```
class House:
    total_houses = 0  # 类属性，存储房屋总数

    def __init__(self, color, number_of_rooms):
        self.color = color  # 实例属性
        self.number_of_rooms = number_of_rooms  # 实例属性
        House.total_houses += 1  # 更新类属性

    def open_door(self):  # 方法
        print("门打开了！")

    def turn_on_lights(self):  # 方法
        print("灯亮了！")
```

在这个例子中：

- `House` 是类名。
- `total_houses` 是一个类属性，用于追踪创建的`House`对象数量。
- `__init__` 是构造器方法，其中`color`和`number_of_rooms`是传入此方法的参数，并被设置为实例属性。
- `open_door` 和 `turn_on_lights` 是定义在类中的其他方法，描述了`House`的行为。

创建`House`类的实例时，例如`my_house = House("红色", 3)`，会自动调用`__init__`方法来初始化这个实例。

这个模板展示了Python中类的基本结构。当然，实际开发中的类可能包含更多复杂的特性，如方法重载、私有属性和方法、类方法和静态方法等。但这个模板提供了一个良好的起点，用于理解和构建Python中的类。

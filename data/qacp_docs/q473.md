# 如何使用列表存储文件中每一行的内容？

**知识点**：File Operations ｜ **问题类型**：Beginner ｜ **答案类型**：Explain in Detail

创建一个包含文件各行内容的列表，就像是把书中的每一行文字都抄写到一个清单（列表）上。在Python中，这可以通过几行简单的代码实现。你只需要打开文件，并把文件的每一行都添加到一个列表中。

这里是一个具体的例子：


# 创建一个空列表，用来存放文件的每一行
lines = []

# 使用with语句打开文件，确保文件会被正确关闭
with open('example.txt', 'r') as file:
    # 循环遍历文件的每一行
    for line in file:
        # 将每一行添加到列表中
        lines.append(line.strip())  # .strip()用于移除行尾的换行符

# 现在，lines列表包含了文件的每一行
print(lines)
在这个例子中：

我们首先创建了一个空列表lines。
使用with open('example.txt', 'r') as file:打开文件。这样做的好处是文件会在with代码块执行完后自动关闭。
然后，我们通过一个for循环读取文件的每一行，使用line.strip()去除每行文字末尾的换行符，然后将处理过的行添加到lines列表中。
最后，当我们退出with块时，lines列表已经包含了文件的所有行，每一行作为列表的一个元素。
这种方法非常适合用于读取和处理文本文件，尤其是当你需要后续处理文件中的每一行时。

# 如何将一个文件的各行内容存储到一个列表中？

**知识点**：File Operations ｜ **问题类型**：Experience in Programming ｜ **答案类型**：Explain in Detail

在Python中，将文件中每一行内容存储到列表可以通过以下两种常用方法实现：

### 方法 1: 逐行读取并添加到列表

适用场景：适合于大型文件或需要逐行处理文件内容的情况。这种方法可以逐步处理每一行，减少内存占用。

```
# 创建一个空列表，用于存放文件的每一行
lines = []

# 使用with语句打开文件，确保文件会被正确关闭
with open('example.txt', 'r') as file:
    # 循环遍历文件的每一行
    for line in file:
        # 将每一行添加到列表中，同时去除行尾的换行符
        lines.append(line.strip())

# 现在，lines列表包含了文件的每一行
print(lines)
```

### 方法 2: 使用 `readlines()` 方法

适用场景：适合于内存足够处理整个文件内容，或者文件相对较小的情况。这种方法代码更简洁，可以快速读取文件的每一行。

```
with open('example.txt', 'r') as file:
    lines = file.readlines()

# 可选的，去除每行末尾的换行符
lines = [line.strip() for line in lines]

print(lines)
```

### 总结

这两种方法都非常适合用于读取和处理文本文件。选择哪一种方法取决于文件的大小、内存的限制以及对代码简洁性的需求。如果你处理的是一个很大的文件，推荐使用方法1；如果文件不大，或者你更倾向于编写简洁的代码，方法2会是一个更好的选择。无论哪种方法，最重要的是理解它们的适用场景和如何根据具体情况做出合适的选择。
